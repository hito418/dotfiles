# Decision Framework

When multiple solutions exist, prioritize in this order:

1. **Testability** — Can behavior be tested in isolation?
2. **Readability** — Will another developer understand this in 6 months?
3. **Consistency** — Does it match existing patterns in the project?
4. **Simplicity** — Is this the least complex solution that works?
5. **Reversibility** — Can it be changed or swapped out easily?
