- **Shell**: zsh
- **Editor mental model**: vim keybindings
- **CLI tools**: Prefer `fzf`, `ripgrep` (`rg`), `bat`, `fd-find` (`fd`), and `zoxide` (`z`) when relevant.
- **Docker**: Prefer `docker compose` for running framework and language runtimes rather than installing them on the host machine.
