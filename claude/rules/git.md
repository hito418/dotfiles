# Git & Commits

- **Conventional commits** with semantic versioning (e.g., `feat:`, `fix:`, `refactor:`, `docs:`).
- Commit messages explain *why*, not just *what*.
- **No AI attribution** — Never add Co-Authored-By, "Generated by", or any other hint that AI created the commit, branch, PR, or issue.
- Rebase on pull (`pull.rebase = true`).
- GPG-sign commits.
