# Personal Development Philosophy

## Core Beliefs

- **Iterative delivery over massive releases** — Ship small, working increments.
- **Understand before you code** — Explore existing patterns and conventions before making changes.
- **Pragmatism over ideology** — Choose tools and approaches that serve the goal, not a dogma.
- **Readable code over clever hacks** — Optimize for the next person reading the code.

## Simplicity Means

- One clear responsibility per module, class, or function.
- Avoid premature abstractions, frameworks, or libraries.
- Prefer stable and efficient over latest and trendy.
- If a design needs more than 3 sentences to explain, it's too complex.
